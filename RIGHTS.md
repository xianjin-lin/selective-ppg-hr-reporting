# Release boundaries and rights

This repository is a selected analysis-code release, not a release of the
complete private project. No permission to access or use withheld training,
inference, figure-generation code, model weights or local research records is
implied by the files published here.

Any code license added to this repository applies only to the published code
it explicitly covers. The rendered manuscript figures and aggregate-result
snapshots remain scholarly materials of the study authors unless separately
licensed. They must not be interpreted as source-dataset redistribution.

Third-party datasets are governed by their providers' terms, not by a software
license in this repository. In particular, the MIMIC-III-Ext-PPG access
agreement and the licenses of the linked PhysioNet VitalDB versions remain
separate. No private data are licensed or distributed here.

If no LICENSE file is present, no additional open-source license has been
granted for the published material. Public visibility alone is not an assertion
that every component of the underlying research project is open source.
